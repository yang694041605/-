## 安全验收

- 通配 CORS 已移除。
- 跨站 Origin 请求返回 403。
- 受信任本机 Origin 获得精确 CORS。
- 渲染和生成接口拒绝客户端提交文件路径。
- 服务端按资产 ID 解析文件，并验证路径位于媒体根目录内。
- 审批记录保存时间轴哈希、素材哈希和提示词版本。
- 素材或提示词变化会让旧审批失效。

## 当前唯一未完成项

真实 Seedance 验收需要同时满足：

1. 开通或续费可调用视频模型的 Agent Plan。

或：

2. 在平台按量 Profile 创建可调用的 Seedance Endpoint，并在模型中心改为 `ep-...`。

同时需要：

3. 提供有权使用的真实新郎、新娘照片。
4. 确认参考视频、音乐和字幕的授权范围。
5. 对 8 个替换镜头逐镜完成身份、串脸、手部、动作、背景、黑边、字幕和音画同步人工审核。

在上述条件满足前，真实人物替换应保持“外部条件阻断”，不能标记为 1.0 商业验收完成。

## 发布形态

当前 1.0 发布形态为：

- 本地 Node 服务。
- 浏览器工作台。
- `npm run build` 生成的 HTML 预览文件。

尚未加入 Electron 安装包或 EXE 打包链。按当前产品范围，网页工作台是正式交付入口；EXE 属于后续桌面包装工作，不影响本地生产 API 和安全边界验收。
