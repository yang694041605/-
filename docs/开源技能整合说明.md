## 采用的原则

### 五幕故事

1. 相识
2. 相知
3. 确认
4. 相伴
5. 承诺

故事采集卡只把新人实际填写的内容写入文案。构图、色光、节奏和微表情可以设计，真实经历、关键物品、对白和因果关系不能凭空补造。

### 14 步确认

应用内向导固定为：

```text
故事采集 → 文案初稿 → 新人确认 → 音色试听 → 完整旁白
→ 分镜设计 → 三个重点静帧 → 剩余图片 → 图生视频
→ BGM 试听 → 试混 → 完整混音 → 字幕预览 → 正式交付
```

每一步记录确认时间和确认结果。没有通过当前步骤时，不会把流程自动跳到交付。

### 素材优先

素材中心是生产的入口，至少包含：

- 新人照片；
- 故事采集卡；
- 服装参考；
- 场景参考；
- 参考视频与生成视频；
- 旁白；
- 配乐；
- 字幕；
- 成片和可编辑工程。

模板解析会从抖音链接下载参考视频，但只提取结构、镜头、节奏和风格，不把参考片原视频冒充客户成片。
