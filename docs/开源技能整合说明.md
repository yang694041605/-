# 核心流程与外部工具

当前版本只保留完成婚礼微电影生产闭环所需的能力。

## 保留

| 能力 | 实现 | 用途 |
| --- | --- | --- |
| 五幕故事与 14 步方法 | `wedding-video-guided-wizard` 方法、项目内工作流 | 故事采集、文案、分镜、审核和交付 |
| 抖音下载与语音转写 | `video-copy-extractor` 外部脚本 | 下载参考片、提取原音频、Whisper 转写 |
| 图片、视频和视觉理解 | 统一模型中心 | 调用已配置的 Seedream、Seedance 或可用替代模型 |
| 旁白 | Windows 本地语音 | 生成 WAV 旁白 |
| 音乐 | 囍映本地原创配乐 | 生成可商用的本地 BGM |
| 剪辑与质检 | 项目内置 Node.js + FFmpeg | 合成、混音、字幕、技术质检和交付包 |

## 已移除

- VVV / Remotion 可选工程入口、模板图片和检查代码。
- `ffmpeg-skill` 可选质检适配器；项目继续使用内置 FFmpeg 质检。
- Edge TTS 外部 Python 依赖；项目继续使用 Windows 本地语音。
- 未实现的 Beatra/Suno 音乐供应商。
- 一次性参考帧分析脚本和图片生成脚本。

抖音下载和 Whisper 转写仍属于核心流程，因此保留；当本机路径不同时，通过 `.env` 中的 `VIDEO_FETCH_SCRIPT`、`VIDEO_ANALYZER_SCRIPT` 和 `CODEX_NODE_MODULES` 覆盖。
