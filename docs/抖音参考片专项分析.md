参考视频：`https://v.douyin.com/Q4ggLtVndZ8/`

参考片里最有价值的不是一句“生成唯美婚礼视频”，而是一份逐镜执行单。画面中出现的视频提示词结构可以整理为：

```text

本镜服装：男主造型编号、女主造型编号
```

参考片中出现的实际句子包括：

> 视频提示词以第一世古代镜头 1 的空场景首帧为起始画面，保持 16:9 横屏、真人电影级写实风格。

> 人物身份必须固定：男主始终保持角色卡 5 左侧面容特征，女主始终保持角色卡 6 左侧面容特征。

> 动作要具有重心、惯性和正确接触关系。环境光保持场景特点，白天明亮通透，室内温暖。

## 2. 音乐怎么配

参考视频 163.2 秒。教程口播约在 118.8 秒结束，随后进入最终微电影回放。

- 新 BGM 在约 `01:58.8–02:00` 之间进入，覆盖口播尾音并接上最终成片。
- 最终回放开始时，音乐已经处于第一个画面，不留空白等待。
- 对最终回放音频做 onset 估算，速度约为 `69.4 BPM`，可按约 70 BPM 理解。
- 开头能量较低，约第 6 秒以后抬升，中段保持稳定，约最后 4 秒收束。
- 参考片的讲解建议是：`0–18 秒舒缓、18–35 秒递进、35–40 秒高潮`。
- 参考片没有在教程中提供 BGM 曲名、作者或授权记录，不能据此认定该音乐可用于商业婚礼项目。

本项目采用的安全配置：

```text
第一个视频画格即开始音乐
0.3–0.8 秒淡入
旁白出现时音乐压低
誓言或拥抱段抬升
结尾随姓名落版淡出
输出响度约 -14 LUFS
True Peak ≤ -1 dBTP
```

## 3. 字幕与字体

参考视频的最终 40 秒婚礼成片在抽样帧中没有发现烧录字幕；画面中出现的字幕主要是教程屏幕录制时的平台自动字幕。

平台字幕的视觉特征：

- 高对比度粗体中文无衬线；
- 白色主体；
- 关键词使用浅黄色强调；
- 黑色细描边和阴影；
- 位于画面底部中央，避开人物脸部。

仅凭视频像素无法可靠确认字体商用名称。外形接近 Microsoft YaHei、PingFang SC 或思源黑体，但不能把“相似”写成确定事实。

本项目成片默认：

```text
字体：Microsoft YaHei
字号：24pt（1280×720）
主色：白色
描边：2px 深灰黑
位置：底部居中
底部安全边距：约 30px
每行最多约 18 个中文字符
```

## 4. 真人照片替换到抖音模板

推荐流程不是直接把一张脸贴到原视频上，而是：

1. 将抖音视频切成 4–8 秒单镜。
2. 每镜提取首帧。
3. 用男女主照片制作唯一身份参考卡。
4. 用 Seedream 把新人身份、服装和场景合成本镜首帧。
5. 用 Seedance 参考原视频动作和运镜生成新镜头。
6. 检查脸、手、服装、背景透视和前后镜动作。
7. 全部通过后进入 FFmpeg / Remotion 剪辑。

### 保持原背景的提示词

```text
以参考视频的构图、景别、机位、人物动作、镜头运动和剪辑节奏为准。
男主角替换为参考图中的[男主姓名]，女主角替换为参考图中的[女主姓名]。
严格保持两人的脸型、五官比例、发际线、发型、肤色和身高差。
保持原参考视频的服装轮廓、手部接触方式、空间透视、背景建筑、道具、光线方向和色调。
人物必须具有真实成年人的面部比例、正确手部结构、自然重心和惯性。
不要改变镜头轴线、动作时长和切点位置。
不要出现文字、水印、黑边、灰色遮罩、多余人物、面部漂移、服装跳变、肢体粘连和换脸特效。
```

### 允许替换背景的提示词

```text
保持参考视频中男女主角的动作、机位、镜头运动、人物占画面比例和切点不变。
将背景替换为[婚礼庭院/民国老街/现代婚礼现场]。
新背景的透视、地平线、主光方向、色温和阴影必须与原人物动作匹配。
保留人物脚底接触阴影、手部接触关系、服装边缘和头发轮廓。
不要改变人物身份和动作，不要产生漂浮、抠图边、遮挡错误或空间方向反转。
```

### 模板模型输入

```bash
arkcli +gen --model <seedance-model> --modality video \
  --input reference_video:@template-shot.mp4 \
  --input reference_image:@groom.jpg \
  --input reference_image:@bride.jpg \
  --ratio adaptive \
  --duration -1 \
  "保持参考视频的人物动作、机位、镜头运动和剪辑节奏；将男主角替换为参考图中的新郎，女主角替换为参考图中的新娘；保持面部身份、服装、手部接触和背景空间连续。"
```

`reference_video` 必须是用户有权使用的模板镜头；`reference_image` 只作为人物身份参考。参考视频时间过长时应先切镜，不把整条 163 秒教程直接提交给 4–15 秒视频模型。

## 5. 剪辑顺序

```text
镜头生成
→ 逐镜检查身份与动作
→ 按模板时间轴粗排
→ 对剪点进行动作匹配
→ 播放 BGM 并确定副歌/高潮位置
→ 旁白与音乐混音
→ 字幕打轴
→ 套用字体样式
→ 检查调色、音量、静帧和字幕安全区
→ 导出 MP4 + SRT + 可编辑工程
```
