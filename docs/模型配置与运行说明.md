真实生成恢复方式：

## 火山方舟恢复方法

先完成浏览器登录：

```powershell
arkcli auth login volc-sso
```

然后在模型中心测试 `Seedream 5.0 Pro` 或 `Seedance 2.0`。当前 API 返回的供应商错误为：

```text
Your account does not have a valid AgentPlan subscription, or your subscription has expired.
```

处理方式只有两种：

1. 续费当前 Agent Plan。
2. 在火山方舟创建可调用的按量推理 Endpoint，并把模型中心里的模型 ID 改为 `ep-...`。

模型资源列表可见不等于有权实际生成。本应用不会把“资源可见”当作“生成成功”。

## 修改模型

在“统一模型中心”中选择对应类别：

- “修改模型”可更新模型 ID 和 Profile。
- “测试连接”只验证当前资源的可见性或本地工具，不提交付费生成。
- “设为默认”只影响后续任务，不覆盖已经完成的素材。
